# LMS SATUSEHAT — Belajar Mandiri v0.7

Prototipe pembelajaran independen untuk pra-UAT publik. **Bukan LMS atau sertifikasi resmi Kementerian Kesehatan RI.**

Repositori ini menyimpan paket website statis LMS SATUSEHAT v0.7, dengan 13 modul, 83 bab, 39 soal kuis modul, dan 312 slide. Tidak menggunakan autentikasi, backend, atau penyimpanan data peserta secara terpusat.

## Deploy

Workflow GitHub Pages melakukan validasi paket dan memublikasikan isi folder `website/` dari arsip rilis pada setiap push ke `main`.

**URL sesudah publikasi berhasil:** https://bofandra.github.io/lms-satusehat/

## Keamanan dan batas

Materi ini masih memerlukan persetujuan hak publikasi dan UAT perangkat nyata; kuis dengan kunci jawaban client-side tidak boleh dijadikan asesmen tersertifikasi. Progres disimpan lokal di browser. Jangan tambahkan data pasien, kredensial, catatan internal, atau informasi fasyankes yang tidak layak dipublikasikan.
